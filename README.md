# Spanisch – Übungen

Interaktive Spanisch-Übungen. Sie laufen offline im Browser.

**Für Schüler:innen:** <https://bildungshexe.github.io/Spanisch/>

| Datei | Inhalt |
| --- | --- |
| `index.html` | Startseite mit Download-Button und Anleitung |
| `tiempos.html` | Tiempos del Pasado y Consecutio Temporum (6 Level, Export der Ergebnisse als JSON) |
| `qr-code.png` | QR-Code zur Startseite (zum Ausdrucken oder Projizieren) |

Die Schüler:innen exportieren am Ende eine JSON-Datei und schicken sie per Mail oder mebis an die Lehrkraft.
Die Auswertungsseite für die Lehrkraft liegt bewusst **nicht** in diesem Repository.
